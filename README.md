# Tugas-P10-Pemrograman-Mobile-M.Lukman-Nul-Hakim
Repository ini berisi project aplikasi Android MoneyTrack untuk tugas P10 Pemrograman Mobile. Aplikasi ini menerapkan SharedPreferences untuk menyimpan pengaturan dan preferensi pengguna secara lokal agar tetap tersimpan meskipun aplikasi ditutup atau dihentikan secara paksa (Force Stop).
